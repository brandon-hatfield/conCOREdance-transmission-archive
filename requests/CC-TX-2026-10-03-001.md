Summary:
ConCOREdance establishes a verified recovery checkpoint with 116 passing tests, append-only assessment review notes, clinician-confirmed report links, restart-tested native PDF preview, and a private cloud source checkpoint.

Body:
The recovery baseline now includes assessment review notes and linked report originals. Review notes are timestamped, append-only entries tied to an assessment revision. Draft and In Review records accept new notes; Final and Amended records preserve their review history without editing controls. Linked amendments begin their own review history while retaining the finalized prior revision.

Assessment reports use the existing encrypted document store. The clinician imports and reviews a PDF, files it as Assessment to the same client, and explicitly confirms its association with an editable assessment revision. Each link retains the assessment answer fingerprint at linking time. Later answer changes produce a visible warning rather than pretending the old PDF reflects the new answers. Linked originals cannot be deleted, reassigned or reclassified, and finalized revisions reject additional links. Complete backups and structured client packets preserve the association and original bytes.

Hands-on verification used an isolated synthetic vault. The pass created a client and embedded assessment draft, saved a review finding, finalized through confirmation, verified read-only final review history, and confirmed persistence after restart. A valid synthetic PDF was then imported, filed to the client, linked to amendment revision 2 after confirmation, and opened in a nested original-document preview. The rendered PDF was inspected directly. Both the report link and original preview survived another restart. The normal installed app was returned to its locked vault, whose encrypted bytes remained unchanged.

Installed alpha 0.1.1 build 20261002211156 remains the verified implementation baseline. The full suite was rerun on October 3: 116 XCTest tests passed with zero failures. A failed amendment save now retains an accessible draft for Retry Save without creating duplicates.

The native recovery source is checkpointed in the private ConCOREdance repository at commit 8f34e6007994e571dce4adbbdd1a14b17ab15678 on branch recovery/verified-alpha-2026-10-03. GitHub readback confirmed the branch, and the cloud source tree exactly matches the reviewed local checkpoint. Existing canonical Git object-directory ownership prevented normal local staging, so the local checkpoint was created in writable external-drive scratch without changing account ownership. The canonical working source remains available in its established project home.

Build and test scratch and packaged outputs now default to Disk 2. If that drive is unavailable, scripts stop unless an explicit override is supplied. Packaging replaces generated app bundles after signature verification and retains rollback only during replacement, rather than accumulating local app backups. Durable source continuity is now verified in private cloud storage.
