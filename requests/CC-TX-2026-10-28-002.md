This entry supplements the earlier October 28 archive reconciliation. A complete new development checkout was created on the SSD from the verified October 3 source. The original checkpoint, October 15 app bundle and historical build artifacts were preserved. The complete original October 15 source was not located; this is an explicitly documented reconstruction, not a claim of byte-identical historical recovery.

Retained Models and NoteReviewView snapshots supplied the note lifecycle structure. Retained pre-unlock VaultStore and Views supplied later note review, finalization, linked amendment and template insertion integration. Missing ClinicalNoteTemplate and VaultUnlockReader implementations, asynchronous unlock coordination, template replacement confirmation and three test suites were written on October 28. Matching the historical total of 136 tests does not establish test-source identity.

A fresh full build and suite passed on this Mac: 136 XCTest tests, zero failures. An opt-in synthetic fixture test also passed and created an isolated encrypted vault. Native validation opened that vault, displayed the final note without editing controls, created and saved a linked amendment, and reopened the vault after a restart with both records retained. No normal clinical vault was opened. The first unlock showed a misleading unsaved-work warning for the deferred audit event. That behavior was corrected and a regression assertion added; all 16 focused lifecycle/template/unlock tests passed afterward. The rebuilt native app then unlocked without that warning. Template replacement confirmation was encountered, but the complete replace-and-save UI action was not verified. The confirmation presentation was changed to an alert and compiled successfully; that final dialog interaction remains an explicit follow-up.

The new deterministic templates preserve each clinician-entered source field once, leave missing information explicit and do not derive a treatment goal from session focus. Template replacement requires a deliberate action. Unlock file reading and the legacy key derivation run outside the UI actor. Duplicate attempts are rejected, cancellation invalidates late results, and automatic protection and termination invalidate pending unlocks. A deferred unlock audit is saved with the next deliberate save rather than rewriting the vault just to read it. Existing queued PDF intake retains its save behavior.
