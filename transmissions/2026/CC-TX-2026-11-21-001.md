# Public site beta visual refresh

**November 21, 2026 · Public website**

The homepage and roadmap use the beta’s gold CORE, italic dance, and tilted compass. The homepage previews show the native vault entrance, caseload, and Calendar Connections. Each opens a full-resolution image in the [visual library](../../archive/assets/). The previous November 17 captures remain available there.

The images came from native SwiftUI/AppKit renders using the local development source corresponding to the isolated beta preview. The vault fixture and the five displayed clients were synthetic. The Calendar view shows the configuration screen without live accounts. The captures document the visible development UI. Release and clinical acceptance are tracked separately.

The website checks covered the homepage and roadmap at 1440, 390, and 320 pixels using Chrome. They verified image loading, horizontal fit, full-size Calendar preview navigation, and mobile menu dismissal with keyboard focus returned to the menu button.

The same-day header refinement reduced the wordmark and aligned the navigation with its lettering. It added visible pointer hover and keyboard focus feedback to the homepage, roadmap, and archive landing pages. Chrome checked the header at 1440, 900, 390, and 320 pixels and exercised the links and mobile menu.

The final header refinement sets the wordmark to 75% of its original website width and lowers the navigation to align with the lettering.
