# Automatic Privacy Protection and Native Print Delivery

October 3 privacy protection and native Print delivery are supported by the retained source checkpoint and 120-test historical verification.

Recorded retrospectively on October 28, 2026. This supplements CC-TX-2026-10-03-001; it does not change that earlier 116-test checkpoint.

The October 3 source checkpoint adds automatic protection after 15 minutes of app inactivity and on sleep, inactive-login-session and screen-lock notifications. Windows, sheets and search toolbars are covered before BPS save/flush. A successful save with no open sheets clears the decrypted vault. Open sheets or a failed save retain editor state behind password authentication. That retained session is a privacy cover, not a cryptographic lock. Actual device sleep was not exercised in the retained validation record.

Print to ConCOREdance was repaired to use a Finder alias to the installed app instead of a stale application copy. The contemporaneous implementation record reports Preview PDF-menu delivery to the same running process, locked import queuing and receipt after synthetic-vault unlock. This is historical UI verification, not a new October 28 UI test.

The full historical suite reached 120 tests with zero failures. The retained SSD checkout is clean at local commit 00c31a9, with source tree 08e63aaf41036f41f63514442294c7059e9787f0. The private GitHub recovery branch currently points to 0420865c8bb742354218ae7684ee17e80c781245. These identify the October 3 baseline, not the later October 15 work.
